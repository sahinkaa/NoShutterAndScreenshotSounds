# 1.0

- Silence photo shutter and screenshot sounds regardless of the ringer switch.
- Handle Camera's separate photo opening and finish cues while preserving completion callbacks.
- Preserve recorded audio and native video start/stop cues.
- Provide an Enabled switch with immediate changes and persistent settings.
- Show the requested icon in the Settings list and above Enabled.
- Build native RootHide and standard rootless packages with matching version 1.0 and canonical package filenames.
- Use standard mobile preference and log paths on rootless with native jailbreak paths on RootHide.

Sound behavior has been verified by the user on iPhone 11 Pro Max, iOS 26.0.1 with Dopamine 3 RootHide. The user also verified the standard rootless package on iOS 16. Targets iOS 15-26; iOS 15 and other versions have not been individually device-tested.
